## Customization Tips

1. **Add your character's personality description** at the beginning
2. **Include your streaming schedule** if you have one
3. **Add links to your social media accounts**
4. **Mention any sponsors or supporters** (if applicable)
5. **Add your Discord/Community server link** if you have a dedicated one
6. **Include donation/support links** if you accept them (Super Chat, Patreon, etc.)

## Notes

- **Character limit**: YouTube video descriptions have a 5,000 character limit. The basic template is well within this limit.
- **Links**: Make sure all links are working and up-to-date before streaming.
- **Localization**: The template includes both Japanese and English for international audiences.
- **Updates**: Remember to update the template if you modify your setup or add new features.
